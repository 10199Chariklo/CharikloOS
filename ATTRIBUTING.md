# Credits & Upstream Acknowledgements

CharikloOS is an independent, native C11 learning framework inspired by the design, viewport mechanics, and structural API paradigms of the ComputerCraft ecosystem.

### 🪐 Primary Inspiration
* **CC: Tweaked:** This project serves as our primary functional benchmark and architectural muse. Our code structures, terminal blit tables, and API progression ramps are designed to map against, reference, and respect the design patterns established by the [CC: Tweaked Repository](https://github.com/cc-tweaked/CC-Tweaked).

### 🛠 Third-Party Subsystem Dependencies
CharikloOS is built to leverage high-quality, community-vetted modular libraries to interact safely with host systems:
* **PhysicsFS:** Used as our underlying raw data decoupling tool to establish secure, sandboxed `/.computerX/` user boundaries without bricking local host environments.
